# Primer prompt para Codex

Copia exactamente este prompt como primera tarea:

---
Trabaja en este repositorio como implementador, no como diseñador.

1. Lee primero `CODEX_INSTRUCTIONS.md`.
2. Después lee únicamente:
   - `README.md`
   - `docs/IMPLEMENTATION_SPEC.md`
   - `docs/FIGMA_REFERENCE.md`
   - `package.json`
   - `src/App.tsx`
3. No explores el resto del repositorio todavía.
4. Instala las dependencias existentes con `npm install`.
5. Ejecuta `npm run build`.
6. Corrige únicamente errores de TypeScript/compilación que impidan construir el proyecto.
7. No cambies diseño, arquitectura, contenido ni dependencias.
8. Al terminar, reporta:
   - errores encontrados;
   - archivos modificados;
   - resultado de `npm run build`;
   - siguiente tarea sugerida, sin ejecutarla.

Mantén el cambio mínimo posible.
