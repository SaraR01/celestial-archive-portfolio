# Sara Retana Pérez — El Archivo Celestial

Starter técnico del portafolio profesional.

## Stack
- React 18
- TypeScript
- Vite
- GSAP
- CSS puro con variables de diseño
- Sin backend
- Sin CMS
- Sin Tailwind en runtime
- ES / EN desde archivos de contenido

## Cómo iniciar
```bash
npm install
npm run dev
```

## Lo que ya está preparado
- Home / Prólogo
- Biblioteca con 6 libros
- Sobre mí
- Experiencia
- Proyectos
- Habilidades
- Formación
- Contacto
- Datos ES / EN
- Enlaces públicos
- Foto personal
- GSAP para introducción y apertura/cierre de libros
- Responsive base
- `prefers-reduced-motion`
